hinge-cli

An unofficial, read-only command-line client for your own Hinge account. Plain, disclosed, scoped.

Install

Download a prebuilt binary for macOS (Apple silicon or Intel), Linux (x86_64) or Windows (x86_64), unpack it and put hinge on your PATH. The macOS and Windows binaries are unsigned, so your OS may ask you to confirm the first run.

Or build from source with Rust 1.85 or newer:

git clone https://github.com/ifthenelse/hinge-cli.git
cd hinge-cli
cargo install --path .

Quickstart

hinge auth capture   # guided, one-time
hinge auth status
hinge tier
hinge limits

Capturing a session needs mitmproxy installed and a phone on the same Wi-Fi. Step by step: docs/auth.md.

Read this first

Using this almost certainly violates Hinge's Terms of Service and can get your account restricted or banned. It never automates a swipe: every action is one explicit command for your own account.
